Build Version 1 of a premium, modern and minimalist real estate website for Madulo Properties.

The website should feel like a serious, established property company: trustworthy, elegant, easy to navigate and strongly focused on helping visitors discover properties and make contact.

I will provide the Madulo Properties logo and imagery separately.

1. CORE OBJECTIVE

Build the actual frontend foundation of the Madulo Properties website.

The priority is:

UI → UX → Design → Responsiveness → User Experience

Do not focus on backend development or API integrations at this stage.

I will provide exact backend/API connection instructions later.

The eventual backend will likely use Node.js, Express.js and MongoDB, but do not make assumptions about the backend now.

Use realistic mock/static data so the entire website can be explored and reviewed.

Do not invent API endpoints, database structures, authentication systems or backend logic.
